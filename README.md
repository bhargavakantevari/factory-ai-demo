### Run

```
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export FLASK_SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
export WEBGOAT_ADMIN_PASSWORD="<choose a strong password>"
FLASK_APP=run.py flask run
```

If `FLASK_SECRET_KEY` is unset, a random key is generated at startup (sessions
do not survive a restart). If `WEBGOAT_ADMIN_PASSWORD` is unset, the `admin`
account gets a random password and cannot be used. Set
`SESSION_COOKIE_SECURE=1` when serving over HTTPS.

### Tests

```
pip install pytest
python -m pytest tests
```

### Vulnerabilities

The vulnerabilities this project originally shipped with (Remote Code
Execution, SQL injection, Insecure Deserialization, Directory Traversal, Open
Redirect, Sensitive Data Exposure, Broken Access Control, Security
Misconfiguration) have been fixed. See `security-report.md` for details. The
original vulnerable code is available in the git history.
